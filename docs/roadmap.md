# Stark — Ideas Roadmap

Unordered list of features discussed. Pick up any of these when the time feels right.

## Voice / Interaction
- **Wake word** ("Hey Stark") — always-on listening without pressing anything
- **Interrupt while speaking** — stop Stark mid-sentence when you want to jump in
- **Voice speed adaptation** — slow down or speed up based on user pace / mood
- **Silence handling / check-in** — if the user goes quiet for a while, gently check in

## Memory & Context
- **Conversation memory across restarts** ✅ *(v0.2.3)* — history persists to `~/.cache/stark/history.json`
- **Better context** — pull clipboard content and selected text into the prompt

## Perception
- **Emotional tone detection** — detect frustration, sadness, excitement from voice and adapt

## Interface
- **Local web UI** — simple browser-based conversation view / settings panel
